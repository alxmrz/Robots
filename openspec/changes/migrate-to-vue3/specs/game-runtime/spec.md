# Spec Delta

## MODIFIED Requirements

### Requirement: Выбор объекта и информация о нём

Пользователь SHALL выбирать билдера кликом левой кнопкой мыши; выбранный билдер визуально
выделяется, а панель информации показывает данные выбранного объекта. Клик по пустому месту
снимает выбор, а клик правой кнопкой выбор не меняет.

#### Scenario: Выбор билдера

- **WHEN** пользователь кликает левой кнопкой по билдеру
- **THEN** билдер становится выбранным и получает визуальное выделение
- **AND** панель информации показывает данные этого объекта

#### Scenario: Снятие выбора

- **WHEN** пользователь кликает левой кнопкой вне выбранного объекта
- **THEN** выделение снимается и панель информации сообщает, что объект не выбран

#### Scenario: Правая кнопка сохраняет выбор

- **WHEN** билдер выбран и пользователь кликает правой кнопкой по сцене
- **THEN** билдер остаётся выбранным и сохраняет выделение
- **AND** билдер получает задачу движения к точке клика

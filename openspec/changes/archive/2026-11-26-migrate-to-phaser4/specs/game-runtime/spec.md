# Spec Delta

## Purpose

Определяет поведение игровой сцены «Robots», которое должно сохраняться при смене версии
движка: инициализация, отрисовка уровня, выбор объектов, поиск пути и движение билдера.

## ADDED Requirements

### Requirement: Запуск игровой сцены

Игра SHALL запускаться на Phaser 4.x с включённой аркадной физикой и инициализировать сцену
уровня без ошибок в консоли браузера.

#### Scenario: Успешный запуск игры

- **WHEN** приложение загружается в браузере
- **THEN** создаётся игра Phaser 4 с аркадной физикой и активной сценой уровня
- **AND** в консоли нет ошибок о недоступном API

#### Scenario: Зависимости соответствуют мажорной версии

- **WHEN** устанавливаются зависимости проекта
- **THEN** установленная версия движка относится к ветке 4.x
- **AND** ни один код проекта не импортирует пакеты, предназначенные для Phaser 3

### Requirement: Отрисовка уровня

Сцена уровня SHALL отображать сетку с шагом ячеек 25 пикселей, покрывающую область канваса,
одного билдера в точке (125, 175) и три стены в точках (200, 150), (200, 180), (200, 220).

#### Scenario: Начальное состояние уровня

- **WHEN** сцена уровня создана
- **THEN** в списке билдеров ровно один объект с точкой (125, 175)
- **AND** в списке стен ровно три стены с указанными координатами
- **AND** сетка видима с шагом 25 пикселей и обводкой ячеек

### Requirement: Выбор объекта и информация о нём

Пользователь SHALL выбирать билдера кликом по нему; выбранный билдер визуально выделяется, а
панель информации показывает данные выбранного объекта. Клик по пустому месту снимает выбор.

#### Scenario: Выбор билдера

- **WHEN** пользователь кликает по билдеру
- **THEN** билдер становится выбранным и получает визуальное выделение
- **AND** панель информации показывает данные этого объекта

#### Scenario: Снятие выбора

- **WHEN** пользователь кликает вне выбранного объекта
- **THEN** выделение снимается и панель информации сообщает, что объект не выбран

### Requirement: Перемещение выбранного объекта

Выбранный объект SHALL двигаться стрелками клавиатуры со скоростью 200 пикселей в секунду и
останавливаться, когда ни одна стрелка не нажата.

#### Scenario: Движение стрелками

- **WHEN** объект выбран и пользователь удерживает стрелку
- **THEN** объект смещается в направлении стрелки со скоростью 200 пикселей в секунду

#### Scenario: Остановка без ввода

- **WHEN** объект выбран и ни одна стрелка не нажата
- **THEN** скорость объекта равна нулю

### Requirement: Поиск пути и движение билдера к цели

При клике правой кнопкой мыши по сцене система SHALL строить путь от текущей позиции билдера к
точке клика по сетке с шагом ячеек 50 пикселей, обходя стены, и перемещать билдера по этому
пути до достижения цели.

#### Scenario: Построение пути к свободной точке

- **WHEN** пользователь кликает правой кнопкой по свободной точке сцены
- **THEN** путь начинается в текущей позиции билдера и заканчивается в точке клика
- **AND** ни одна точка пути не пересекается со стеной

#### Scenario: Достижение цели

- **WHEN** билдер проходит все точки построенного пути
- **THEN** билдер останавливается в целевой точке
- **AND** временные маркеры цели и промежуточных точек удаляются из сцены

#### Scenario: Столкновение со стеной прерывает движение

- **WHEN** движущийся билдер сталкивается со стеной
- **THEN** движение по текущему пути останавливается

### Requirement: Постановка строительных задач

Билдер SHALL накапливать задачи на строительство стены, башни, ворот и фабрики роботов, а при
выполнении задачи создавать соответствующий объект в сцене и добавлять его в список билдеров.

#### Scenario: Накопление задач

- **WHEN** у билдера запрашивают строительство стены, башни и ворот
- **THEN** в очереди инструкций билдера три задачи
- **AND** перемещение билдера не добавляет строительных задач

#### Scenario: Выполнение задачи

- **WHEN** билдер выполняет задачу строительства
- **THEN** в сцене появляется объект соответствующего типа в точке билдера
- **AND** задача удаляется из очереди

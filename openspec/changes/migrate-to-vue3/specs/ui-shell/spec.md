# Spec Delta

## Purpose

Определяет интерфейсную оболочку «Robots»: загрузку интерфейсного приложения, размещение
игрового канваса внутри страницы, панель сведений о выбранном объекте и отображение
координат курсора, а также корректное освобождение игрового движка при размонтировании.

## ADDED Requirements

### Requirement: Запуск интерфейсного приложения

Приложение SHALL монтироваться в элемент страницы с идентификатором `app` и отображать
игровую область вместе с панелью управления.

#### Scenario: Успешная загрузка страницы

- **WHEN** пользователь открывает собранную страницу игры
- **THEN** внутри элемента `#app` отображается интерфейс с игровой областью и панелью
  управления
- **AND** в консоли браузера нет ошибок инициализации интерфейса

#### Scenario: Версия интерфейсной библиотеки

- **WHEN** устанавливаются зависимости проекта
- **THEN** установленная версия `vue` относится к ветке 3.x
- **AND** в зависимостях нет пакетов, предназначенных только для Vue 2

### Requirement: Размещение игрового канваса

Игровой движок SHALL создавать канвас размером 1075×625 пикселей внутри элемента
`#gameContainer`, который уже присутствует в документе на момент запуска игры.

#### Scenario: Канвас внутри контейнера

- **WHEN** интерфейс смонтирован и игра запущена
- **THEN** канвас игры является потомком элемента `#gameContainer`
- **AND** размер канваса — 1075×625 пикселей
- **AND** в документе ровно один игровой канвас

### Requirement: Панель информации о выбранном объекте

Панель «Информация по объекту» SHALL показывать имя и текущие координаты выбранного
объекта, обновлять их при его перемещении и сообщать, что объект не выбран, когда выбор
снят.

#### Scenario: Выбранный объект

- **WHEN** пользователь выбирает билдера в игровой области
- **THEN** панель показывает имя `Builder` и текущие координаты билдера

#### Scenario: Отсутствие выбора

- **WHEN** выбор снят
- **THEN** панель показывает сообщение «Объект не выбран»

#### Scenario: Перемещение выбранного объекта

- **WHEN** выбранный объект смещается стрелками клавиатуры
- **THEN** координаты в панели соответствуют новому положению объекта

### Requirement: Координаты курсора

Интерфейс SHALL отображать координаты указателя мыши в пределах игровой области.

#### Scenario: Движение мыши над игровой областью

- **WHEN** пользователь перемещает указатель над игровой областью
- **THEN** поля координат показывают текущие X и Y указателя относительно игрового канваса

### Requirement: Освобождение игры при размонтировании

Интерфейс SHALL уничтожать игровой экземпляр и связанные с ним обработчики, когда игровая
область удаляется со страницы.

#### Scenario: Размонтирование игровой области

- **WHEN** игровая область удаляется из документа
- **THEN** игровой экземпляр уничтожается и прекращает обновлять сцену
- **AND** канвас игры больше не присутствует в документе

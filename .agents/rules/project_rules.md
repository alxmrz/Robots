# Правила проекта

Локальные правила, дополняющие `.agents/rules/alxmrz_kit_general_rules.md`. Файл не
перезаписывается `agent-kit`, поэтому проектные договорённости держим здесь.

## Инкапсуляция

- Клиентский код не обращается к свойствам объекта напрямую — только через методы.
  Чтение — геттером (`point.getX()`), запись — сеттером (`point.setX(x)`) или
  осмысленной командой (`builder.moveRight(dx)`).
- Запрещено даже для чтения:

  ```js
  // нельзя: обходим интерфейс объекта и привязываемся к его полям
  this.moveTo.moveTo(destination.x, destination.y);
  expect(wall.point.x).toBe(10);
  ```

  ```js
  // можно: объект сам решает, как отдать или принять своё состояние
  this.moveTo.moveTo(destination.getX(), destination.getY());
  expect(wall.getPoint().getX()).toBe(10);
  ```

- Свои собственные поля класс использует свободно — ограничение про внешний,
  клиентский код. `this.point` внутри `Destination` — норма, `destination.point`
  снаружи — нет.
- Если данных для клиента не хватает, добавь метод на объекте (геттер, `getInfo()`),
  а не читай поле в обход.
- Поля фреймворка (`Phaser.GameObjects.*`, DOM, `game.input.*`) — часть внешнего API
  библиотеки; правило к ним не применяется, обращайся так, как предписывает библиотека.

## Тесты

- Не проверяй возвращаемое значение метода через чтение того же состояния, из которого
  этот метод его берёт. Пример запрещённой проверки:

  ```js
  // getPoint() возвращает this.point — сравнение тавтологично
  // (и обращение к obj.point нарушает правило инкапсуляции выше)
  expect(obj.getPoint()).toBe(obj.point);
  ```

  Такая проверка проходит при любой реализации геттера (даже если он возвращает не то
  поле) и ловит только грубые падения — ценности как тест не несёт.
- Задавай ожидание независимо от проверяемого кода: через сеттер или через конструктор.

  ```js
  // через конструктор
  const point = new Point(15, 25);
  expect(point.getX()).toBe(15);

  // через сеттер
  point.setX(5);
  expect(point.getX()).toBe(5);
  ```

- Для ссылок на объекты прокидывай экземпляр снаружи (конструктором или сеттером) и
  сравнивай с этим же внешним экземпляром:

  ```js
  const point = new Point(15, 25);
  const destination = new Destination(point, createScene());
  expect(destination.getPoint()).toBe(point);
  ```

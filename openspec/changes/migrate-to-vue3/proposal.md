# Proposal: переход на Vue 3

## Why

Проект работает на Vue 2 (`vue` `^2.6.12`), поддержка которого завершена (EOL 31.12.2023):
обновлений безопасности и совместимости с актуальными инструментами сборки больше нет.
Интерфейсная оболочка маленькая — три компонента без Vuex, Router и собственных директив, —
поэтому переход на Vue 3 дешевле сделать сейчас, чем после появления нового UI. Заодно
миграция закрывает видимый дефект: панель «Информация по объекту» не реагирует на выбор
билдера, хотя спека `game-runtime` этого требует.

## What Changes

- **BREAKING** для сборочной обвязки: `vue` 2.x → `^3.5`, `vue-loader` 15 → `^17`,
  добавляется `@vue/compiler-sfc`, удаляется `vue-template-compiler`, `vue-style-loader`
  становится явной зависимостью.
- Точка входа: `new Vue({ render }).$mount('#app')` заменяется на
  `createApp(App).mount('#app')`.
- Компоненты `App.vue`, `layouts/Main.vue`, `Game.vue` переводятся на Composition API
  (`<script setup>`); разметка, стили и поведение интерфейса сохраняются.
- `Game.vue` создаёт `Phaser.Game` после монтирования DOM и передаёт движку элемент
  контейнера, а при размонтировании компонента уничтожает игру.
- Сцена уведомляет интерфейс о смене выбранного объекта; панель показывает имя и текущие
  координаты выбранного билдера и сбрасывается при снятии выбора. Сейчас панель не
  обновляется вовсе, а прежний `JSON.stringify` игрового объекта упал бы на циклических
  ссылках `Phaser.GameObjects`.
- Уточняется обработка указателя: выбор выполняется кликом левой кнопки, клик правой
  кнопкой выбор не меняет (иначе обработчик перемещения к цели теряет выбранного билдера).
- Webpack: `VueLoaderPlugin` из `vue-loader` 17, feature-flags Vue 3 через `DefinePlugin`,
  алиас `vue$` удаляется — используется `vue.runtime.esm-bundler.js` по умолчанию.
- Документация (`README.md`, `AGENTS.md`) описывает Vue 3 и новые подводные камни.

Игровая логика на Phaser 4, поиск пути и строительные задачи не меняются.

## Capabilities

### New Capabilities

- `ui-shell`: интерфейсная оболочка на Vue 3 — загрузка приложения, монтирование игры
  внутри контейнера компонента, панель информации о выбранном объекте, показ координат
  курсора и освобождение ресурсов при размонтировании.

### Modified Capabilities

- `game-runtime`: уточняется требование «Выбор объекта и информация о нём» — выбор
  выполняется левой кнопкой, правая кнопка выбор не меняет, сцена отдаёт интерфейсу плоские
  данные выбранного объекта.

## Impact

- `package.json` / `package-lock.json`: `vue` 3.x, `vue-loader` 17, `@vue/compiler-sfc`,
  явный `vue-style-loader`; удаление `vue-template-compiler`.
- `webpack.config.js`: загрузчик и плагин Vue 3, `DefinePlugin` с feature-flags, алиас.
- `src/main.js`, `src/components/App.vue`, `src/components/layouts/Main.vue`,
  `src/components/Game.vue`.
- `src/Level.js`: регистрация выбора и обработки правого клика выносится в методы, добавляются
  `selectPlayer`, `setPlayerChangeHandler` и уведомление интерфейса.
- `src/Builder.js`: `getInfo()` с плоскими данными объекта.
- `tests/unit/Level.test.js`, `tests/unit/Builder.test.js`: тесты выбора и `getInfo`.
- Jest-конфиг и Phaser не меняются; `.vue`-компоненты, как и раньше, не покрываются
  unit-тестами.
- Риски: ESM-сборка Vue 3 предупреждает об отсутствии feature-flags; момент появления
  контейнера в DOM влияет на то, куда Phaser вставляет канвас.
